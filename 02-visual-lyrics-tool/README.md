# 可视化歌词工具项目

## 项目概述

### 背景
kevin唱歌五音不全，实际上是因为听的不准。那么能不能做一个工具/软件，能够可视化每首歌，把每首歌的歌词，用波形、音高、文字的大小、高矮、长短来体现它的变化。让耳朵不利的人也能听懂唱好歌。

### 目标
- 解决痛点：五音不全→听不准→可视化辅助
- 让耳朵不利的人也能唱好歌
- 考虑申请专利

### 核心功能
1. **音频分析**：提取歌曲的波形、音高数据
2. **可视化渲染**：将数据映射到文字的视觉属性
   - 波形 → 文字横向波动
   - 音高 → 文字高低/粗细
   - 音量 → 文字大小
3. **播放同步**：歌词与音频精准同步
4. **交互辅助**：实时反馈辅助演唱

### 技术方案
- 前端：React/Vue + Canvas/WebGL
- 音频处理：Python (librosa) 或 Web Audio API
- AI能力：音高识别、节奏检测
