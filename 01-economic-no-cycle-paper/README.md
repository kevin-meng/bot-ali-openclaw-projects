# 经济无周期论文项目

## 项目概述

### 背景
现在主流经济学的观点是经济是有周期的。但是我想说经济其实是没有周期的。因为随着不同的时代，它有不同的背景，那么它有不同的变量在里边，其实只要信息流动的足够充分，那么危机其实远不会到来。

### 目标
- 写一篇论文来阐述上述观点
- 证明写论文并不难
- 上传Arxiv
- 积累个人名声

### 核心论点
1. 主流"经济周期"理论存在局限性
2. 时代背景不同导致经济变量不同
3. 信息流动充分时，危机可以被预见和避免
4. 经济本质上是非周期性的

## 论文规划

### 章节结构
1. 摘要
2. 引言 - 主流经济周期理论回顾
3. 理论框架 - 信息流动与经济稳定性
4. 案例分析 - 不同历史时期的对比
5. 结论与展望
