# 飞书权限设置指南

## 背景
飞书权限 API 较为复杂，建议通过界面手动设置以确保正确配置。

## 多维表格权限设置

### 操作步骤

1. **打开多维表格**
   - URL: https://cq2m55n7zyi.feishu.cn/base/QLtHbEuMnainFGsjTLVcfXzdnTb

2. **进入设置**
   - 点击右上角 **"..."** （更多操作）
   - 选择 **"设置"**

3. **协作与权限**
   - 点击 **"协作与权限"**
   - 点击 **"邀请协作者"**

4. **添加用户权限**
   ```
   用户: 孟凡荣 (ou_34c112747e125521c17128d191864d73)
   权限级别: 所有者 ✅
   ```

5. **添加公司成员权限**（可选）
   ```
   对象: 公司全员或指定团队
   权限级别: 可编辑 📝
   ```

6. **保存**
   - 点击 **"保存"** 使设置生效

## 文档权限设置

### 使用子技能自动设置
创建文档时使用 `feishu-doc-creator-with-permission` 子技能，会自动完成：
- 添加用户为协作者
- 转移所有权（如果需要）

## 常见问题

### Q: 权限不生效？
A: 确保点击了"保存"按钮，有时需要刷新页面。

### Q: 如何删除协作者？
A: 在协作与权限列表中，找到对应用户，点击右侧 **"移除"**。

### Q: API 设置失败怎么办？
A: 建议通过界面手动设置，API 可能有版本或权限限制。
