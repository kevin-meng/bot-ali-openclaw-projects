# 海外常识教育App系列

## 项目概述

### 背景
- 海外很多人重视素质教育
- 但很多人缺乏一些基本的常识
- 市面上的教育软件要么太复杂，要么太贵

### 目标
- 做一系列软件
- 每个软件只有基础功能
- 功能主要是针对常识类的
- 比如说以国家相关的文化科技：something about xxx (Country)
- 做成iOS平台App
- 付费模式
- 出海，赚钱

### 产品特点
1. **轻量级**：每个App只有基础功能，不做复杂
2. **垂直领域**：专注于特定常识领域（如某个国家的文化、科技等）
3. **付费**：采用付费下载模式
4. **出海**：面向海外市场

### 示例方向
- "Something about Japan" - 日本文化科技常识
- "Something about USA" - 美国文化科技常识
- "Something about UK" - 英国文化科技常识
- 以此类推，每个国家做一个App

### 面临的挑战
1. 苹果开发者账号申请
2. 海外发布流程
3. 支付渠道
4. 推广获客
5. 如何打造自己的壁垒（防止抄袭）

### 壁垒思考
1. 内容深度：独家整理的常识内容
2. 用户体验：极简精美的UI设计
3. 品牌积累：系列App形成的品牌效应
4. 持续更新：不断推出新国家/新主题
