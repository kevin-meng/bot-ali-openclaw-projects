# 2026-02-16 工作日志

## 飞书日历 MCP 调试进展

### 问题
用户想让我在梦繁的个人日历上创建日程，但 MCP 使用 app_access_token 只能看到 AgentBot 日历。

### 解决方案
需要获取 UAT (User Access Token) 才能访问用户个人日历。

### 当前状态
- MCP 配置正确，有 app_id、app_secret、FEISHU_USE_APP_TOKEN
- 但 app_access_token 只能访问应用被授权的日历（AgentBot）
- 无法访问用户个人日历

### 待解决
- 梦繁需要手动获取 User Access Token：
  1. 打开 https://open.feishu.cn/api-explorer/
  2. 选择 authen → getUserAccessTokenBy3rdApp
  3. 获取 token 后发给我

### 经验总结
- `FEISHU_USE_APP_TOKEN=true` 仍然使用 app_access_token
- 要获取用户身份，需要配置 refresh_token 或 user_access_token
- OAuth 授权需要在浏览器完成，服务器无法执行
