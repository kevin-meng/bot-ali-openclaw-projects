### API 路径修复
- **问题**：`client.calendar.v4CalendarsPrimary.get()` 返回 undefined
- **原因**：飞书 SDK API 路径结构不同
- **解决**：改为 `client.calendar.v4.calendar.get()`
- **验证方法**：`node -e "console.log(Object.keys(client.calendar.v4 || {}))"`

### SDK 参数格式问题修复
- **错误**：`request miss calendar_id path argument`
- **原因**：SDK 参数使用 `params` 而非 `path`
- **解决**：所有 API 调用改为 `{ path: { calendar_id: xxx }, data: {...} }`
- **参考**：bitable.ts 的 `client.bitable.appTableRecord.create({ path: {...}, data: {...} })`
