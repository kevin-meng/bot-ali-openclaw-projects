# 头马革命军

## 项目概述

### 背景
头马（Toastmasters）是老牌的演讲国际俱乐部，有近百年的历史。但是kevin发现现在的头马有一点跟不上时代了：
- 网站效率低
- 工作效率很低
- 会员费很贵
- 服务跟不上

### 目标
- 与其被动接受，不如倒逼改变
- 创建一个新的俱乐部，走着老头马的路
- 命名为"头马革命军"
- 既具备头马的优势，也有改进它的不足
- 提供更低的会员费
- 提供更好的服务
- 提供更多实用的工具
- 让演讲得到更多锻炼

### 计划
1. 上半年先做一个类似的演讲，在小范围内先把这个想法说出来
2. 看有多少人响应
3. 如果响应的人多，就把它打造成一个平台
4. 采用老的头马模式，作为非盈利组织进行运维

### 扩展方向
- 在国内的高校/学校当中进行普及推广
- 对于下一代的素质教育有很好的作用

### 核心功能规划
1. **演讲训练**：提供实用工具和训练方法
2. **社区运营**：更高效的工作流程
3. **会员服务**：更低的费用，更好的体验
4. **教育推广**：面向学生群体的素质教育
