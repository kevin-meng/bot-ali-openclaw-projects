# 13-本地AI搜索应用

## 项目状态：规划中

## 进度：0%

## 项目背景

参考秘塔AI搜索（metaso.cn），在本地开发一个类似的AI搜索引擎。

## 秘塔AI搜索特点
- 无广告，直达结果
- AI智能摘要
- 支持文件上传分析
- 结构化回答
- API接口

## 项目目标

在本地搭建一个AI搜索应用，核心功能：
1. **搜索入口**：用户输入查询关键词
2. **AI抓取**：自动抓取搜索结果网页
3. **智能摘要**：用AI提取关键信息
4. **结构化输出**：整理成易读的答案
5. **追问功能**：支持连续对话

## 技术方案

### 后端
- Python: Playwright/Selenium（网页抓取）
- FastAPI/Flask（API服务）
- LLM: OpenAI/Claude API

### 前端
- Next.js/React
- 流式输出展示

### 核心模块
1. 搜索代理（调用搜索API或爬虫）
2. 网页内容提取
3. AI摘要生成
4. 对话历史管理

## MVP功能
1. 输入关键词 → 返回AI摘要结果
2. 流式输出回答
3. 简单对话历史
