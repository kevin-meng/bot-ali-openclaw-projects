# 职业考试备考平台

## 项目概述

### 背景（公司战略层面）
kevin在半个月前给领导提了一个战略建议：在消费金融强监管背景下，公司应探索更多出路。

战略建议核心：关于战略布局职业培训场景，构建公司自有流量与增长新引擎的建议
- 当前金融科技与小贷行业正经历深度调整期
- 强监管常态化、利率持续下行
- 传统模式同质化竞争加剧
- 建议：公司应战略性进军职业教育领域
- 打造免费职业赋能平台
- 构建"教育+就业+金融"的产融结合新生态

### 本项目方向：职业考试备考平台

#### 核心方案
1. 依据现在最近的职业考试
2. 收集他们的教材
3. 借助AI从教材里抽取核心的知识点
4. 准备出相应的网页App
5. 服务于备考的人员
6. 提供免费的服务
7. 吸引他们注册

#### 变现路径
- 当用户人数上到一定规模：
  - 对外的数据服务：可以做一个数据供应商去售卖客户的信息
  - 基于用户在平台上的行为数据：做风险类的模型和识别
  - 推金融类的产品

### 产品功能规划
1. **教材收集**：各职业考试教材汇总
2. **AI知识提取**：自动抽取核心知识点
3. **在线学习**：网页/App呈现
4. **题库练习**：历年真题、模拟题
5. **学习进度**：记录用户学习轨迹
6. **数据分析**：用户行为数据沉淀

### 技术方案
- 前端：React/Vue网页 + 移动端适配
- 后端：Python FastAPI
- AI：LLM用于知识抽取、题目生成
- 数据库：用户数据、学习数据存储

### 目标用户
- 备考各类职业资格考试的人群
- 需要提升职业技能的职场人士
