# 户外多功能滑板车

## 项目概述

### 背景
kevin平时喜欢户外徒步，但是徒步走久了觉得很累。尤其走在修好的路面上，虽然平整，但一直走也很累。

### 目标
- 设计一款多功能滑板车，放在背包里
- 人在省力的同时，还能携带方便
- 申请专利
- 通过众筹平台去海外众筹
- 做得非常新潮、时尚
- 借助中国供应链解决

### 设计概念（已有草图）
- **结构**：三个轮子
- **折叠**：可以折叠
- **刹车**：后轮作为刹车
- **收纳**：不用的时候可以类似于构成一个拉杆箱
- **便携**：可放入背包
- **省力**：让人省力行走

### 核心优点
1. 便携 - 可折叠，易于携带
2. 省力 - 减少行走负担
3. 多功能 - 多种使用模式

### 面临的挑战
1. 折叠结构的设计和实现
2. 重量控制
3. 耐用性
4. 安全性

### 产品规划
1. **概念设计**：完善产品设计图
2. **原型开发**：制作原型样品
3. **专利申请**：保护核心技术
4. **供应链**：寻找中国供应商
5. **海外众筹**：Kickstarter/Indiegogo等平台
6. **市场营销**：打造新潮时尚形象
