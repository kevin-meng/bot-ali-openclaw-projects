## 二、核心功能

### 2.1 用户系统

| 功能 | 实现方式 |
|------|----------|
| 注册 | 邮箱/手机号 + 密码 |
| 登录 | JWT Token |
| 鉴权 | Bearer Token |

**数据库设计**：

```sql
-- 用户表
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(255) UNIQUE,
    phone VARCHAR(20),
    password_hash VARCHAR(255),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT TRUE
);

-- API Key表
CREATE TABLE api_keys (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT,
    key_value VARCHAR(64) UNIQUE,
    name VARCHAR(100),
    call_limit INT DEFAULT 1000,  -- 每日限制
    call_count INT DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 调用日志
CREATE TABLE api_logs (
    id INT PRIMARY KEY AUTO_INCREMENT,
    api_key_id INT,
    endpoint VARCHAR(100),
    status INT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/auth/register | POST | 用户注册 |
| /api/auth/login | POST | 用户登录 |
| /api/keys | GET | 获取API Key列表 |
| /api/keys | POST | 创建API Key |
| /api/keys/{id} | DELETE | 删除API Key |
| /api/quote/today | GET | 获取今日名言 |
| /api/quote/random | GET | 获取随机名言 |
| /api/quote/generate | POST | AI生成名言 |

### 2.3 API Key机制

```
用户调用流程：
1. 用户注册/登录
2. 创建API Key（如 "我的应用"）
3. 调用API：Authorization: Bearer sk_xxxxx
4. 系统验证Key有效性 + 扣减次数
5. 返回名言数据
```

**Key格式**：`sk_` + 32位随机字符串

## 三、安全设计

### 3.1 鉴权

- JWT Token：有效期7天
- API Key：长期有效，可自主管理
- Rate Limiting：每个Key每日1000次

### 3.2 限流

| 级别 | 限制 | 说明 |
|------|------|------|
| 免费 | 100次/天 | 基础用户 |
| 个人 | 1000次/天 | 付费用户 |
| 企业 | 无限 | 定制客户 |

## 四、部署方案

### 4.1 Docker化

```dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0"]
```

### 4.2 环境变量

```bash
DATABASE_URL=mysql://user:pass@localhost:3306/quote_db
REDIS_URL=redis://localhost:6379
MINIMAX_API_KEY=sk-xxx
JWT_SECRET=your-secret-key
```
