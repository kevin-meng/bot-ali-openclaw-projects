#### 1.2.2 LGD模型（Loss Given Default）

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 违约损失率模型 (LGD Model)                    │
│  模型用途: 估计客户违约后的损失比例                        │
│  Y标签定义:                                              │
│    Y = 1 - (回收金额 / 违约敞口)                        │
│  样本选取:                                                │
│    - 仅包含已违约账户                                     │
│    - 违约后24个月为表现期                                │
│    - 正样本≥2000                                         │
└─────────────────────────────────────────────────────────┘
```

**LGD计算公式:**

```
LGD = 1 - Recovery Rate

Recovery Rate = 回收金额 / 违约敞口

违约敞口 = 违约时本金 + 违约时利息 + 违约时费用
回收金额 = 还款金额 + 担保物价值 + 追偿金额
```

#### 1.2.4 期望损失模型（EL Model）

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 期望损失模型 (Expected Loss)                  │
│  模型用途: 计量预期信用损失，用于拨备计提                  │

└─────────────────────────────────────────────────────────┘
```

**EL计算框架:**

```python
def calculate_expected_loss(credit, PD, LGD, EAD):
    """
    计算期望损失
    """
    # 单笔期望损失
    EL_single = PD * LGD * EAD
    
    # 组合期望损失
    EL_portfolio = sum(EL_single)
    
    # 边际期望损失
    Marginal_EL = EL_portfolio - EL_portfolio_without_account
    
    return EL_single, EL_portfolio, Marginal_EL
```

#### 1.2.5 风险价值模型（VaR）

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 风险价值模型 (Value at Risk)                  │
│  模型用途: 计量给定置信水平下的最大可能损失                │
│  VaR = 在险价值                                         │
└─────────────────────────────────────────────────────────┘
```

**VaR计算方法:**

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| 历史模拟法 | 基于历史损失分布 | 数据充足 |
| 参数法 | 假设正态分布 | 正常市场 |
| 蒙特卡洛 | 模拟大量场景 | 复杂产品 |
| 压力测试 | 极端情景分析 | 尾部风险 |

```python
# 历史模拟法 VaR
def calculate_var_historical(losses, confidence=0.99):
    """
    99% VaR: 损失分布的1%分位数
    """
    var = np.percentile(losses, (1-confidence)*100)
    return var

# 参数法 VaR (正态假设)
def calculate_var_normal(mean, std, confidence=0.99):
    """
    VaR = mean + z * std
    """
    z = stats.norm.ppf(1-confidence)
    var = mean + z * std
    return var
```

#### 1.2.7 经济资本模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 经济资本计量模型                               │
│  模型用途: 计量覆盖非预期损失所需的资本                    │
│  经济资本 = VaR - 期望损失                               │
└─────────────────────────────────────────────────────────┘
```

**经济资本计算:**

```python
def calculate_economic_capital(portfolio, confidence=0.999):
    """
    经济资本 = 在险资本 - 期望损失
    
    参数:
        confidence: 置信水平 (99.9% = 3.1σ)
    """
    # 计算期望损失
    EL = sum(PD * LGD * EAD)
    
    # 计算风险敞口分布
    risk_distribution = simulate_loss_distribution(portfolio)
    
    # 计算VaR
    VaR = np.percentile(risk_distribution, (1-confidence)*100)
    
    # 经济资本
    EC = VaR - EL
    
    return EC
```

#### 2.2.1 风险定价模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 风险定价模型                                   │
│  模型用途: 根据风险水平确定贷款利率                        │
│  价格 = 资金成本 + 运营成本 + 风险成本 + 目标利润        │
└─────────────────────────────────────────────────────────┘
```

**定价公式:**

```
r = r_f + r_op + r_risk + r_profit

其中:
    r_f = 资金成本率
    r_op = 运营成本率
    r_risk = 风险成本率 = PD × LGD / (1-1/(1+r)^n)
    r_profit = 目标利润率
```

**风险定价示例:**

```python
def risk_based_pricing(PD, LGD, EAD, tenor, 
                       funding_cost=0.04, 
                       operation_cost=0.02,
                       target_roi=0.15):
    """
    风险定价模型
    """
    # 风险成本 (考虑货币时间价值)
    risk_cost = (PD * LGD) / (1 - 1/(1+funding_cost)**tenor)
    
    # 总定价
    total_rate = funding_cost + operation_cost + risk_cost + target_roi
    
    # 差异化定价
    if PD < 0.01:  # 优质客群
        total_rate -= 0.01
    elif PD > 0.05:  # 高风险客群
        total_rate += 0.02
    
    return total_rate
```

**定价策略矩阵:**

| 客群等级 | PD范围 | 定价区间 | 额度策略 |
|----------|--------|----------|----------|

| 良好 | 1-3% | 12-18% | 20-30万 |
| 中等 | 3-8% | 18-24% | 10-20万 |
| 风险 | 8-15% | 24-36% | 5-10万 |
| 高风险 | >15% | >36% | 拒绝 |

#### 2.2.2 RAROC模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 风险调整资本回报模型 (RAROC)                   │
│  模型用途: 评估每单位资本创造的收益                        │
│  RAROC = (收入 - 成本 - 预期损失) / 经济资本            │
└─────────────────────────────────────────────────────────┘
```

**RAROC计算:**

```python
def calculate_raroc(revenue, cost, EL, EC):
    """
    RAROC = (净收益 - 期望损失) / 经济资本
          = (收入 - 运营成本 - 资金成本 - EL) / EC
    """
    net_revenue = revenue - cost
    risk_adjusted_revenue = net_revenue - EL
    
    if EC == 0:
        return float('inf')
    
    raroc = risk_adjusted_revenue / EC
    
    return raroc

# 决策标准
def decision(raroc, hurdle_rate=0.15):
    """
    hurdle_rate: 最低收益率要求
    """
    if raroc >= hurdle_rate:
        return "批准"
    else:
        return "拒绝"
```

**RAROC应用:**

| 场景 | 决策标准 |
|------|----------|
| 贷款审批 | RAROC > 15% |
| 产品定价 | 确保 RAROC > 12% |
| 客户准入 | 综合 RAROC > 10% |
| 资产组合 | 组合 RAROC > 12% |

#### 2.2.3 客户盈利模型（LTV）

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 客户生命周期价值模型 (LTV)                     │
│  模型用途: 评估客户全生命周期贡献                        │
│  LTV = Σ (收入 - 成本) / (1+r)^t                        │
└─────────────────────────────────────────────────────────┘
```

**LTV计算框架:**

```python
def calculate_ltv(customer, years=5, discount_rate=0.10):
    """
    客户生命周期价值
    """
    cash_flows = []
    
    for year in range(1, years+1):
        # 收入项
        interest_income = calculate_interest(customer, year)
        fee_income = calculate_fees(customer, year)
        cross_sell_income = calculate_cross_sell(customer, year)
        
        # 成本项
        funding_cost = calculate_funding_cost(customer, year)
        operation_cost = calculate_operation_cost(customer, year)
        risk_cost = calculate_risk_cost(customer, year)
        
        # 年度现金流
        annual_cf = (interest_income + fee_income + cross_sell_income 
                   - funding_cost - operation_cost - risk_cost)
        
        cash_flows.append(annual_cf)
    
    # 折现
    ltv = sum(cf / (1+discount_rate)**t for t, cf in enumerate(cash_flows, 1))
    
    return ltv
```

|------|---------|------|
| S | >50000 | 战略客户，优先服务 |
| A | 20000-50000 | 高价值，深度运营 |
| B | 5000-20000 | 成长客户，培养转化 |
| C | <5000 | 低价值，自动化运营 |

#### 2.2.4 资产定价模型

┌─────────────────────────────────────────────────────────┐
│  模型名称: 资产证券化定价模型                             │
│  模型用途: 为信贷资产转让/ABS提供定价参考                 │

**资产池定价:**

```python
def asset_pool_pricing(pool, 
                       base_rate=0.05,
                       risk_premium=0.02,
                       service_fee=0.005):
    """
    资产池定价
    """
    # 加权平均违约率
    pool_pd = weighted_average(pool, 'PD')
    
    # 加权平均损失率
    pool_lgd = weighted_average(pool, 'LGD')
    
    # 加权平均期限
    pool_tenor = weighted_average(pool, 'tenor')
    
    # 基础收益
    base_income = base_rate
    
    # 风险溢价
    risk_premium_calc = pool_pd * pool_lgd
    
    # 服务费
    service = service_fee
    
    # 发行价格
    issuance_price = base_income + risk_premium_calc + service
    
    return issuance_price
```
