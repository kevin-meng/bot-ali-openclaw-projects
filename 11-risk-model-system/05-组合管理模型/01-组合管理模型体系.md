# 组合管理模型体系

## 模型优先级说明

| 优先级 | 评分 | 说明 |
|--------|------|------|
| **P0** | 9-10分 | 核心防线，必须优先开发 |
| **P1** | 7-8分 | 重要风控，显著提升风控效果 |
| **P2** | 5-6分 | 优化补充，提升风控精细度 |
| **P3** | 3-4分 | 锦上添花，后续迭代 |

---

## 一、风险计量模型（10个）

### 1.1 风险指标模型

#### 1. 预期损失率模型（EL）[P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 预期损失率(EL)计量模型 |
| **模型类型** | 计量模型 |
| **业务目标** | 计量单笔/组合的预期损失 |

**样本选取**

- **样本范围**: 全量贷款组合
- **数据周期**: 至少24个月历史数据
- **粒度**: 客户级 + 产品级 + 组合级

**Y标签定义**

- **EL = PD × LGD × EAD**
  - PD: 违约概率（来自评分卡）
  - LGD: 违约损失率（历史回收率）
  - EAD: 违约敞口（未偿本金+利息）

**模型开发**

- **PD模型**: 见各阶段评分卡
- **LGD模型**: 
  - LGD = 1 - 回收率
  - 回收率 = 实际回收金额 / 违约敞口
  - 按产品、逾期阶段、催收方式等维度建模
- **EAD模型**:
  - 考虑提前还款、额度使用率
  - EAD = 已用额度 × CCF(信用转换系数)

**注意事项**:
> - EL是计提准备金的核心依据
> - 需符合会计准则（IFRS9或CAS22）
> - 建议按季度更新参数

#### 2. 违约概率（PD）标定模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | PD校准模型 |
| **模型类型** | 回归 |
| **业务目标** | 将模型输出的评分转换为实际违约概率 |

**样本选取**

- **样本**: 有完整表现期的客户

**Y标签定义**

- **Y**: 实际违约率（按评分分组统计）

**模型开发**

- **方法**: 
  - 静态池验证：同一池的历史违约率
  - 迁移率分析：各状态间的迁移矩阵
  - 边际PD验证：时间序列PD变化
- **校准方法**: Platt Scaling / Isotonic Regression

**注意事项**:
> - PD需与实际违约率匹配，否则准备金计提不准
> - 建议每年至少校准一次
> - 监管检查重点关注PD准确性

#### 3. 违约损失率（LGD）模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | LGD计量模型 |
| **模型类型** | 回归 |
| **业务目标** | 准确计量不同客户/产品的违约损失率 |

**样本选取**

- **样本**: 已结清（正常结清或违约结清）的贷款
- **违约定义**: 90天+逾期或核销

**Y标签定义**

- **Y = 1 - 回收率**
- **回收率 = (偿还金额 - 催收成本) / 违约敞口**

**模型开发**

- **特征**:
  - 客户特征：收入、资产、信用历史
  - 贷款特征：金额、期限、担保方式
  - 逾期特征：逾期天数、逾期阶段
  - 催收特征：催收方式、催收时长
- **算法**: Beta Regression / Tobit模型

**注意事项**:
> - LGD影响准备金和资本计量
> - 不同产品LGD差异大，需分产品建模

#### 4. 违约敞口（EAD）模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | EAD计量模型 |
| **模型类型** | 回归 |
| **业务目标** | 准确计量违约时的敞口金额 |

**样本选取**

- **样本**: 违约客户

**Y标签定义**

- **Y**: 违约时点未偿本金 + 应收利息

**模型开发**

- **特征**:
  - 额度使用率历史变化
  - 提前还款行为
  - 产品特性（是否循环额度）
- **CCF设定**:
  - 循环额度: CCF = 80-100%
  - 非循环: CCF = 100%

**注意事项**:
> - 循环额度EAD计算复杂，需考虑未来使用情况
> - 建议CCF按产品设定

### 1.2 风险组合模型

#### 5. 风险迁徙模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 风险状态迁徙模型 |
| **模型类型** | 时序/矩阵 |
| **业务目标** | 监控资产在不同风险状态间的迁徙 |

**样本选取**

- **状态定义**: 正常 → 关注 → 次级 → 可疑 → 损失
- **迁徙矩阵**: 穆迪/标普格式

**Y标签定义**

- **迁徙概率**: 从状态i转移到状态j的概率

**模型开发**

- **计算方法**:
  - 累计迁徙率 = 各月迁徙率乘积
  - 边际迁徙率 = 单月迁徙概率
- **应用**: 
  - 计提准备金
  - 预测未来资产质量

**注意事项**:
> - 迁徙率是资产质量变化的前瞻指标
> - 建议按月监控迁徙矩阵

#### 6. 资产质量预测模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 资产质量迁徙预测模型 |
| **模型类型** | 时序预测 |
| **业务目标** | 预测未来资产质量变化趋势 |

**样本选取**

- **时间跨度**: 至少36个月

**Y标签定义**

- **Y**: 未来各状态分布

**模型开发**

- **算法**: Markov Chain + 蒙特卡洛模拟
- **预测周期**: 3/6/12个月

**注意事项**>
> - 预测未来不良率变化
> - 需考虑宏观经济影响

#### 7. 组合VaR模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 组合风险价值(VaR)模型 |
| **模型类型** | 计量模型 |
| **业务目标** | 计量组合在给定置信水平下的最大损失 |

**样本选取**

- **组合数据**: 全量资产

**Y标签定义**

- **VaR**: 在95%/99%置信水平下，未来特定时间段的最大损失

**模型开发**

- **方法**:
  - 历史模拟法
  - 方差-协方差法
  - Monte Carlo模拟
- **参数**:
  - 置信水平: 95% / 99%
  - 持有期: 1天 / 10天 / 1年
- **特征**: 单一产品VaR + 组合分散化效应

**注意事项**>
> - VaR是风险管理的核心指标
> - 监管要求资本计量基于99.5%置信水平

#### 8. 风险集中度模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 风险集中度监测模型 |
| **模型类型** | 监控/计量 |
| **业务目标** | 监测组合风险集中度 |

**样本选取**

- **维度**: 行业、地区、产品、客群、渠道

**Y标签定义**

- **集中度指标**: 
  - 单一客户/行业敞口占比
  - 单一产品占比
  - 地区集中度

**模型开发**

- **监测维度**:
  - 行业集中度: Top 10行业占比
  - 客户集中度: 大额客户敞口
  - 地区集中度: 区域分布
  - 产品集中度: 产品类型分布
- **预警阈值**: 
  - 单一行业 > 30%
  - 单一客户 > 10%
  - 单一地区 > 40%

**注意事项**>
> - 集中度风险是系统性风险的来源
> - 建议分散化配置资产

### 1.3 准备金模型

#### 9. 减值准备计量模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 贷款减值准备计量模型 |
| **模型类型** | 计量模型 |
| **业务目标** | 按会计准则计量减值准备 |

**样本选取**

- **样本**: 全部贷款资产

**Y标签定义**

- **准备金额**: 
  - 个别评估: 单笔贷款未来现金流折现
  - 组合评估: 同类资产池的预期损失

**模型开发**

- **方法**:
  - 个别方式: 已识别减值贷款
  - 组合方式: 相同风险特征资产分组
- **参数**: PD × LGD × EAD（见前述模型）
- **折现率**: 实际利率或类似贷款当前利率

**注意事项**>
> - 减值准备直接影响利润
> - 需符合IFRS9或国内会计准则
> - 需经审计确认

#### 10. 压力测试模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 风险压力测试模型 |
| **模型类型** | 情景分析 |
| **业务目标** | 评估极端情景下的损失影响 |

**样本选取**

- **情景设定**: 
  - 基准情景
  - 轻度压力
  - 中度压力
  - 重度压力

**Y标签定义**

- **Y**: 各情景下的预期损失、不良率、资本充足率

**模型开发**

- **压力参数**:
  - GDP增速下降
  - 失业率上升
  - 房价下跌
  - 利率变化
  - 行业冲击
- **方法**: 敏感性分析 + 情景分析

**注意事项**>
> - 监管要求定期开展压力测试
> - 建议每年至少一次全面压力测试

## 二、定价收益模型（5个）

### 2.1 收益模型

#### 11. RAROC模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 风险调整资本回报率(RAROC)模型 |
| **模型类型** | 计量模型 |
| **业务目标** | 评估单笔/组合的真实回报 |

**样本选取**

- **样本**: 全部贷款组合

**Y标签定义**

- **RAROC = (收入 - 成本 - 预期损失) / 经济资本**

**模型开发**

- **收入**: 利息收入 + 手续费收入
- **成本**: 运营成本 + 资金成本
- **预期损失**: EL（来自前述模型）
- **经济资本**: 基于VaR计算

**注意事项**>
> - RAROC>15%为良好
> - 低于资本成本的业务需调整

#### 12. 客户利润率模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 客户利润率分析模型 |
| **模型类型** | 归因分析 |
| **业务目标** | 分析单个客户的利润贡献 |

**样本选取**

- **样本**: 全部客户

**Y标签定义**

- **客户利润** = 利息收入 + 费用收入 - 资金成本 - 运营成本 - 风险损失 - 获客成本

**模型开发**

- **成本分摊**:
  - 获客成本: 按渠道分摊
  - 运营成本: 按业务量分摊
  - 资金成本: 按敞口分摊
- **应用**: 客户价值评估、资源分配

#### 13. 产品收益模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 产品线收益分析模型 |
| **模型类型** | 归因分析 |
| **业务目标** | 分析各产品线的盈利能力 |

**样本选取**

- **样本**: 全部产品

**Y标签定义**

- **产品利润** = 产品收入 - 产品成本 - 产品风险损失

**模型开发**

- **维度**:
  - 产品类型
  - 期限
  - 金额区间
  - 渠道

### 2.2 资本模型

#### 14. 经济资本模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 经济资本计量模型 |
| **模型类型** | 计量模型 |
| **业务目标** | 计量各业务所需的经济资本 |

**样本选取**

- **样本**: 全部资产组合

**Y标签定义**

- **经济资本**: 为覆盖非预期损失所需的资本

**模型开发**

- **计算方法**:
  - 信用风险: 基于PD/LGD/EAD分布
  - 市场风险: VaR模型
  - 操作风险: 基本指标法/标准法
- **置信水平**: 99.5%（根据监管要求）

#### 15. 资本充足率预测模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 资本充足率预测模型 |
| **模型类型** | 时序预测 |
| **业务目标** | 预测未来资本充足率变化 |

**样本选取**

- **时间跨度**: 至少12个季度

**Y标签定义**

- **Y**: 未来各时点资本充足率

**模型开发**

- **参数**:
  - 风险加权资产变化
  - 资本变化（利润、融资）
  - 资产质量变化
- **监管要求**: 
  - 一级资本 ≥ 8.5%
  - 资本充足率 ≥ 10.5%
  - 缓冲资本: 2.5%

**注意事项**>
> - 资本充足率是生命线
> - 低于监管要求需补充资本

## 风险管理指标体系

### 核心指标

| 指标 | 定义 | 监管要求/内部阈值 |
|------|------|-------------------|
| 不良率(NPL) | 不良贷款/总贷款 | < 2% |
| 逾期率 | 逾期贷款/总贷款 | < 3% |
| 拨备覆盖率 | 减值准备/不良贷款 | > 150% |
| 贷款迁徙率 | 正常→不良的迁徙比例 | 监控趋势 |
| 资本充足率 | 资本/风险加权资产 | > 10.5% |
| RAROC | 风险调整回报率 | > 15% |

---

> **文档说明**
> - 组合管理模型共15个：风险计量模型10个 + 定价收益模型5个
> - 组合管理模型是风控体系的高级应用，服务于资产负债管理和战略决策
> - **P0优先级模型建议优先开发**
> - 需要与业务系统、财务系统、监管报送系统紧密对接
