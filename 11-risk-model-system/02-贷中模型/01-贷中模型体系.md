# 贷中风控模型体系

## 模型优先级说明

| 优先级 | 评分 | 说明 |
|--------|------|------|
| **P0** | 9-10分 | 核心防线，必须优先开发 |
| **P1** | 7-8分 | 重要风控，显著提升风控效果 |
| **P2** | 5-6分 | 优化补充，提升风控精细度 |
| **P3** | 3-4分 | 锦上添花，后续迭代 |

## 一、额度管理模型（8个）

### 1.1 动态额度管理

#### 1. 额度使用率监控模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 额度使用率监控模型 |
| **模型类型** | 时序监控 |
| **业务目标** | 实时监控客户额度使用情况 |

**样本选取**

- **样本范围**: 全部存量客户
- **监控频率**: 每日
- **时间窗口**: 最近30天使用情况

**Y标签定义**

- **Y**: 额度使用率 = 已用额度 / 总授信额度

**模型开发**

- **特征**: 当前使用率、历史平均使用率、使用率变化趋势
- **阈值设定**: 使用率>80%触发关注

**注意事项**:
> - 额度使用率是客户需求的信号
> - 使用率>80%且持续上升需关注
> - 使用率突然降至0可能是流失前兆

#### 2. 额度调整触发模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 额度调整自动触发模型 |
| **模型类型** | 二分类 |
| **业务目标** | 自动识别需要调整额度的客户 |

**样本选取**

- **触发场景**: 提额申请、被动调整、系统自动触发
- **样本量**: 不少于20000条调整记录

**Y标签定义**

- **Y=1**: 调整后客户风险表现恶化
- **Y=0**: 调整后客户保持良好表现

**模型开发**

- **触发条件**:
  - 连续6个月正常还款
  - 收入增长≥20%
  - 额度使用率≥70%
  - 客户主动申请
- **算法**: XGBoost

**注意事项**:
> - 提额是把双刃剑，好客户提额后可增加收益，风险客户提额会扩大损失
> - 建议提额幅度≤20%/次
> - 需监控提额客户的后续表现

#### 3. 提额收益评估模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 提额收益评估模型 |
| **模型类型** | 回归 |
| **业务目标** | 评估提额后预期收益增加 |

**样本选取**

- **样本**: 历史提额客户

**Y标签定义**

- **Y**: 提额后新增利息收入 - 新增风险损失

**模型开发**

- **算法**: 线性回归
- **决策**: 预期收益>0 建议提额

**注意事项**:
> - 提额收益需覆盖风险成本
> - 需动态调整阈值

#### 4. 降额预警模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 降额风险预警模型 |
| **模型类型** | 二分类 |
| **业务目标** | 识别需要降低额度的风险客户 |

**样本选取**

- **样本**: 历史降额客户

**Y标签定义**

- **Y=1**: 降额后客户风险状况改善
- **Y=0**: 降额后客户无明显改善

**模型开发**

- **触发条件**:
  - 连续2期逾期
  - 风险评分下降超过阈值
  - 负债率超过80%
  - 出现涉诉信息

**注意事项**:
> - 降额需谨慎，可能导致客户流失
> - 建议先预警再降额，给客户缓冲期
> - 降额后需持续监控

## 二、风险预警模型（8个）

### 2.1 早期预警模型

#### 9. 30天逾期预警模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 30天逾期预测模型 |
| **模型类型** | 二分类 |
| **业务目标** | 提前30天预测客户是否会逾期 |

**样本选取**

- **样本范围**: 历史有还款记录的客户
- **样本量**: 正负样本1:3
- **时间窗口**: 观察期3个月，表现期1个月

**Y标签定义**

- **Y=1**: 未来30天内发生逾期
- **Y=0**: 未来30天保持正常

**模型开发**

- **特征维度**:
  - 还款行为特征：还款时间分布、还款金额波动、提前还款频率
  - 账户特征：额度使用率、借款频次、账龄
  - 外部特征：征信查询变化、负债变化
- **算法**: LightGBM
- **KS要求**: ≥0.45
- **召回率要求**: ≥0.70（在既定precision下）

**注意事项**:
> - 这是贷中最重要的预警模型，直接影响M1逾期的发现时间
> - 召回率需≥70%，漏报成本高
> - 建议预警后立即触发催收动作
> - 维信金科客户年轻化，需关注还款习惯不稳定

#### 10. 60天逾期预警模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 60天逾期预测模型 |
| **模型类型** | 二分类 |
| **业务目标** | 提前预测客户是否会演变为严重逾期 |

**样本选取**

- **观察期**: 6个月
- **表现期**: 2个月

**Y标签定义**

- **Y=1**: 未来60天出现60天+逾期
- **Y=0**: 未出现严重逾期

**模型开发**

- **特征**: 同30天预警，增加历史严重逾期次数、多头借贷变化
- **策略优先级**: 高于30天预警

**注意事项**:
> - M2客户催收难度显著增加
> - 建议预警后升级催收方式

#### 11. 90天逾期预警模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 90天严重逾期预测模型 |
| **模型类型** | 二分类 |
| **业务目标** | 预测客户是否会演变为坏账 |

**样本选取**

- **观察期**: 12个月
- **表现期**: 3个月

**Y标签定义**

- **Y=1**: 出现90天+逾期
- **Y=0**: 未出现90天+逾期

**模型开发**

- **算法**: XGBoost + Logistic Regression组合
- **应用**: 预留充足催收时间

**注意事项**:
> - M3+基本属于坏账预备队
> - 建议提前60天预警，给催收预留时间

### 2.2 行为预警模型

#### 12. 还款行为异常检测模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 还款行为异常检测模型 |
| **模型类型** | 异常检测 |
| **业务目标** | 检测异常还款行为 |

**样本选取**

- **样本**: 历史正常还款客户的行为数据

**Y标签定义**

- **Y=1**: 存在异常行为（非正常原因导致的还款异常）
- **Y=0**: 正常还款行为

**模型开发**

- **算法**: Isolation Forest + 规则引擎
- **异常特征**:
  - 还款金额异常（每次刚好还最低还款额）
  - 还款时间异常（总是在最后时刻还款）
  - 还款来源异常（固定时间点有大额资金转入）

**注意事项**:
> - "精养账单"是欺诈的前兆
> - 最低还款可能是资金紧张的信号
> - 建议与反欺诈团队联动

#### 13. 负债恶化预警模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 负债恶化预警模型 |
| **模型类型** | 二分类 |
| **业务目标** | 监控客户负债变化趋势 |

**样本选取**

- **时间窗口**: 近6个月负债变化

**Y标签定义**

- **Y=1**: 负债率上升超过20%且风险表现恶化
- **Y=0**: 负债在可控范围

**模型开发**

- **特征**: 负债率变化、新增负债笔数、负债来源分布

**注意事项**:
> - 负债恶化是逾期的先兆
> - 建议每月定期查询征信变化
> - 关注网贷新增情况

#### 14. 关联风险预警模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 关联风险传导预警模型 |
| **模型类型** | 图计算/二分类 |
| **业务目标** | 识别关联客户的风险传导 |

**样本选取**

- **关联关系**: 联系人、工作单位、家庭地址、IP、设备等

**Y标签定义**

- **Y=1**: 关联客户出现风险
- **Y=0**: 关联客户正常

**模型开发**

- **算法**: 图神经网络 + 风险传播模型
- **应用**: 对关联客户进行风险排查

**注意事项**:
> - 欺诈团伙通常有关联
> - 建议关联客户同时降额或冻结

**Y标签定义**

- **Y**: 区域逾期率变化趋势

**模型开发**

## 三、交叉营销模型（4个）

### 3.1 产品推荐模型

#### 17. 交叉销售机会识别模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 交叉销售机会识别模型 |
| **模型类型** | 二分类 |
| **业务目标** | 识别适合交叉销售的目标客户 |

**样本选取**

- **正样本**: 成功交叉销售且后续表现良好的客户
- **负样本**: 未接受交叉销售或接受后表现不好的客户

**Y标签定义**

- **Y=1**: 接受交叉销售且后续正常还款
- **Y=0**: 拒绝或接受后逾期

**模型开发**

- **特征**: 客户画像、产品偏好、购买时机、渠道偏好

#### 18. 产品匹配度模型 [P2-4分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 客户产品匹配度模型 |
| **模型类型** | 推荐算法 |
| **业务目标** | 为客户推荐最适合的产品 |

**样本选取**

- **样本**: 全部客户与产品组合

**Y标签定义**

- **Y**: 客户对产品的满意度/留存率

**模型开发**

- **算法**: 协同过滤 + 内容推荐
- **特征**: 客户特征、产品特征、行为特征

### 3.2 客户激活模型

#### 19. 沉睡客户激活模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 沉睡客户激活模型 |
| **模型类型** | 二分类 |
| **业务目标** | 识别可激活的沉睡客户 |

**样本选取**

- **定义**: 90天以上无借款行为的客户
- **正样本**: 成功激活且后续活跃的客户
- **负样本**: 无法激活或激活后不活跃的客户

**Y标签定义**

- **Y=1**: 激活后30天内发生借款行为
- **Y=0**: 激活后无行为

**模型开发**

- **特征**: 历史活跃度、沉睡时长、客户价值、偏好产品

**注意事项**:
> - 沉睡客户唤醒成本低于新客获取
> - 建议对高价值沉睡客户优先激活

#### 20. 客户流失预警模型 [P2-6分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 客户流失预警模型 |
| **模型类型** | 二分类 |
| **业务目标** | 提前预警可能流失的客户 |

**样本选取**

- **定义**: 180天无任何借款行为的客户
- **正样本**: 已经流失的客户
- **负样本**: 保持活跃的客户

**Y标签定义**

- **Y=1**: 未来90天内无任何借款行为
- **Y=0**: 保持活跃

**模型开发**

- **特征**: 活跃度下降趋势、额度使用率变化、登录频次变化

**注意事项**:
> - 流失客户挽回困难
> - 建议流失前干预（如利率优惠）
