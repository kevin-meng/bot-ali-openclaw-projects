### 1.3 额度策略规则

```python
# 额度计算公式
def calculate_credit_limit(customer):
    base_limit = customer.monthly_income * income_multiplier
    
    # 风险调整
    risk_score = risk_model.predict(customer.features)
    risk_factor = map_risk_to_factor(risk_score)  # 0.3-1.5
    
    # 资产调整
    asset_factor = calculate_asset_factor(customer.assets)
    
    # 最终额度
    final_limit = base_limit * risk_factor * asset_factor
    
    # 额度边界
    final_limit = clip(final_limit, MIN_LIMIT, MAX_LIMIT)
    
    return final_limit
```

#### 3.2.2 客户价值模型（LTV）

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 客户生命周期价值模型                           │
│  模型用途: 评估客户长期价值，指导资源投入                  │
│  Y标签定义:                                              │
│    Y=1: 12个月LTV ≥ 500元                               │
│    Y=0: 12个月LTV < 500元                                │
│  LTV计算:                                                │
│    LTV = 利息收入 + 服务费收入 - 运营成本 - 风险成本     │
└─────────────────────────────────────────────────────────┘
```

**LTV计算公式:**

```python
def calculate_ltv(customer, months=12):
    # 利息收入
    interest_income = sum(monthly_interest)
    
    # 服务费收入
    fee_income = sum(annual_fee + transaction_fee)
    
    # 运营成本
    operation_cost = marketing_cost + service_cost
    
    # 风险成本
    risk_cost = expected_loss * credit_limit
    
    # LTV
    ltv = interest_income + fee_income - operation_cost - risk_cost
    
    return ltv
```

**客户分层:**

| 层级 | LTV范围 | 运营策略 |
|------|---------|----------|
| S级 | >5000 | 专属服务、优先权益 |
| A级 | 2000-5000 | 高价值维护、交叉销售 |
| B级 | 500-2000 | 常规运营、优惠激活 |
| C级 | <500 | 成本控制、自动化服务 |
