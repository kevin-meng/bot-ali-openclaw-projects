### 1.2 核心催收模型

#### 1.2.1 催收评分模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 智能催收评分模型                               │
│  模型用途: 评估逾期客户还款概率，指导催收资源分配          │
│  Y标签定义:                                              │
│    Y=1: 催收后30天内还清欠款                             │
│    Y=0: 催收后30天内未还清                              │
│  样本选取:                                                │
│    - 观察期: 逾期发生后7天                               │
│    - 表现期: 催收动作后30天                              │
│    - 样本量: 正样本≥3000, 负样本≥8000                   │
└─────────────────────────────────────────────────────────┘
```

**样本分层:**

| 逾期阶段 | 正样本定义 | 样本占比 |
|----------|------------|----------|
| M1 (1-30天) | 30天内还清 | 40% |
| M2 (31-60天) | 30天内还清 | 30% |
| M3 (61-90天) | 30天内还清 | 20% |
| M3+ (90天+) | 30天内还清 | 10% |

**特征维度:**

| 类别 | 特征数 | 示例 |
|------|--------|------|
| 客户画像 | 15 | 年龄、职业、收入、资产 |
| 逾期特征 | 20 | 逾期天数、逾期金额、逾期原因 |
| 历史表现 | 15 | 历史逾期次数、历史还款记录 |
| 联系方式 | 10 | 电话接通率、地址有效性 |
| 外部数据 | 15 | 社保、税务、法院数据 |
| 催收反馈 | 10 | 历史催收记录、承诺还款 |

#### 1.2.2 失联预测模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 失联风险预测模型                               │
│  模型用途: 预测客户失联风险，提前采取保全措施              │
│  Y标签定义:                                              │
│    Y=1: 未来14天内无法联系（电话/短信/上门均无响应）     │
│    Y=0: 14天内成功联系                                  │
│  样本选取:                                                │
│    - 观察期: 逾期发生后                                 │
│    - 表现期: 14天观察窗口                               │
│    - 排除: 已还款客户                                   │
└─────────────────────────────────────────────────────────┘
```

**失联信号特征:**

| 特征类别 | 关键指标 | 权重 |
|----------|----------|------|
| 联系历史 | 电话接通率 | 高 |
| 联系历史 | 短信回复率 | 高 |
| 行为特征 | 地址真实性 | 中 |
| 行为特征 | 联系人有效性 | 高 |
| 外部信号 | 涉诉信息 | 高 |
| 外部信号 | 运营商状态 | 中 |

**失联等级划分:**

| 等级 | 失联概率 | 策略 |
|------|----------|------|
| 低 | <20% | 常规催收 |
| 中 | 20-50% | 加强联系频率 |
| 高 | 50-80% | 多种渠道并行 |
| 极高 | >80% | 启动实地访查 |

#### 1.2.3 账龄滚动模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 逾期滚动预测模型                               │
│  模型用途: 预测客户从当前逾期阶段向更严重阶段发展的概率     │
│  Y标签定义:                                              │
│    Y=1: 30天内从M1滚动到M2/M3                           │
│    Y=0: 30天内保持M1或还清                              │
│  样本选取:                                                │
│    - 观察期: 刚进入M1时点                                │
│    - 表现期: 30天后状态                                  │
│    - 样本量: 根据各阶段滚动率确保足够正样本               │
└─────────────────────────────────────────────────────────┘
```

**滚动矩阵:**

| 当前状态 | 滚动到M2 | 滚动到M3+ | 还清 | 保持 |
|----------|----------|-----------|------|------|
| M1 | 15% | 5% | 50% | 30% |
| M2 | - | 20% | 40% | 40% |
| M3 | - | - | 30% | 70% |

```
┌─────────────────────────────────────────────────────────┐
```

| 外访催收 | 高 | 高 | M2-M3 |
| 诉讼催收 | 极高 | 极高 | M3+ |
| 委外催收 | 高 | 高 | M2+ |

## 二、诉讼模型（4个）

### 2.1 诉讼模型矩阵

| 模型名称 | 功能 | Y标签 | 适用阶段 |
|----------|------|-------|----------|
| 诉讼必要 性模型 | 是否值得起诉 | 诉讼回收 | M3+ |
| 诉讼时机模型 | 最佳起诉时点 | 回收效果 | M3+ |
| 诉讼成本模型 | 预估诉讼费用 | 成本准确性 | 诉前评估 |
| 执行效果模型 | 执行回款预测 | 执行回款 | 判决后 |

### 2.2 核心诉讼模型

#### 2.2.1 诉讼必要性模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 诉讼必要性评估模型                             │
│  模型用途: 评估案件是否值得通过诉讼方式追偿               │
│  Y标签定义:                                              │
│    Y=1: 诉讼后成功回款                                  │
│    Y=0: 诉讼后未回款                                    │
│  样本选取:                                                │
│    - 已完成诉讼的案件                                    │
│    - 样本量: 正样本≥500, 负样本≥1000                    │
└─────────────────────────────────────────────────────────┘
```

**评估特征:**

| 类别 | 特征 | 说明 |
|------|------|------|
| 被诉主体 | 是否有资产 | 房产、车辆、股权 |
| 被诉主体 | 资产可执行性 | 是否已抵押、查封 |
| 债务人特征 | 是否有共同债务人 | 追偿对象 |
| 债务人特征 | 历史履行意愿 | 是否曾还款 |
| 诉讼成本 | 预计诉讼费 | 与标的额相关 |
| 诉讼成本 | 预计执行费 | 与执行难度相关 |
| 时间成本 | 诉讼周期 | 平均6-12个月 |

**决策规则:**

```
诉讼收益 = 预计回收金额 - 诉讼成本 - 时间成本

if 诉讼收益 > 0 and 胜诉概率 > 70%:
    建议起诉
else:
    建议委外或核销
```

#### 2.2.2 诉讼时机模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 最佳诉讼时机模型                               │
│  模型用途: 确定最佳的起诉时间点                           │
│  Y标签定义:                                              │
│    Y=1: 此时机起诉后成功回款                            │
│    Y=0: 此时机起诉后未回款                              │
│  样本选取:                                                │
│    - 不同起诉时点的历史案件                               │
└─────────────────────────────────────────────────────────┘
```

**时机因素:**

| 因素 | 最佳时机 | 说明 |
|------|----------|------|
| 逾期账龄 | M6+ | 账龄越长回收越难 |
| 财产状态 | 有新增财产时 | 财产线索出现后 |
| 诉讼时效 | 届满前6个月 | 避免时效风险 |
| 季节因素 | 年末/年初 | 债务人资金回流期 |

#### 2.2.3 执行效果模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 执行回款预测模型                               │
│  模型用途: 判决后预测可执行回款金额                       │
│  Y标签定义:                                              │
│    Y=1: 实际执行回款>预测的80%                          │
│    Y=0: 实际执行回款<预测的80%                          │
│  样本选取:                                                │
│    - 已完成执行的案件                                    │
└─────────────────────────────────────────────────────────┘
```

**执行特征:**

| 特征类别 | 指标 |
|----------|------|
| 被执行人资产 | 房产、车辆、银行存款、股权 |
| 查封冻 结情况 | 首封/轮候查封 |
| 债务人状态 | 在逃/下落不明/已死亡 |
| 共有财产 | 是否有共有财产需析产 |
| 他案执行 | 是否涉及其他债务执行 |

## 📊 催收效果评估指标

### 3.1 核心KPI

| 指标 | 计算方式 | 目标值 |
|------|----------|--------|
| 回收率 | 已回收金额 / 逾期总额 | ≥60% |
| 催回率 | 回收案件数 / 逾期案件数 | ≥50% |
| 首单回收率 | 首次催收回收比例 | ≥30% |
| 承诺兑现率 | 承诺还款实际履行率 | ≥70% |
| 失联率 | 失联案件 / 总案件 | ≤15% |

### 3.2 账龄回收率参考

| 逾期阶段 | 催收回收率目标 | 行业参考 |
|----------|----------------|----------|
| M1 | 80-90% | 85% |
| M2 | 60-70% | 65% |
| M3 | 40-50% | 45% |
| M3+ | 15-25% | 20% |
