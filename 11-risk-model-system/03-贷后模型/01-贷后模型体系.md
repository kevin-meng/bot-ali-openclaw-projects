# 贷后风控模型体系

## 模型优先级说明

| 优先级 | 评分 | 说明 |
|--------|------|------|
| **P0** | 9-10分 | 核心防线，必须优先开发 |
| **P1** | 7-8分 | 重要风控，显著提升风控效果 |
| **P2** | 5-6分 | 优化补充，提升风控精细度 |
| **P3** | 3-4分 | 锦上添花，后续迭代 |

## 一、催收模型（10个）

### 1.1 催收评分模型

#### 1. 催收响应预测模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 催收响应概率预测模型 |
| **模型类型** | 二分类 |
| **业务目标** | 预测客户对催收行为的响应概率 |

**样本选取**

- **样本范围**: 历史被催收的客户
- **样本量**: 不少于50000条催收记录
- **时间窗口**: 观察期3个月，表现期1个月

**Y标签定义**

- **Y=1**: 催收后7天内客户有还款行为
- **Y=0**: 催收后7天内无还款行为

**模型开发**

- **特征维度**:
  - 客户特征：年龄、收入、历史逾期次数、负债率
  - 逾期特征：逾期天数、逾期金额、逾期阶段
  - 催收特征：催收方式、催收时间、催收频次
  - 历史响应：历史响应率、历史还款完成率
- **算法**: LightGBM
- **KS要求**: ≥0.40

**注意事项**:
> - 催收资源有限，需优先分配给响应概率高的案件
> - 建议分层：P0(响应率>70%)、P1(40-70%)、P2(<40%)
> - 首次催收响应率最高，需重点把握

#### 2. 催收难度评估模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 催收难度分级模型 |
| **模型类型** | 多分类 |
| **业务目标** | 评估催收难度以制定差异化策略 |

**样本选取**

- **样本**: 历史催收案件

**Y标签定义**

- **Y**: 容易催收/一般/困难/极困难（4分类）
- **定义标准**:
  - 容易：催收1-2次即还款
  - 一般：催收3-5次还款
  - 困难：催收6次以上或需协商
  - 极困难：需诉讼或核销

**模型开发**

- **算法**: 随机森林
- **应用**: 分配催收资源和策略

**注意事项**:
> - 极困难案件建议直接进入诉讼流程
> - 不同难度匹配不同催收策略

#### 3. 还款意愿预测模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 客户还款意愿评估模型 |
| **模型类型** | 二分类 |
| **业务目标** | 评估客户主观还款意愿 |

**样本选取**

- **样本**: 进入催收流程的客户

**Y标签定义**

- **Y=1**: 客户有明确还款承诺且实际履行
- **Y=0**: 客户承诺但不还款或拒绝沟通

**模型开发**

- **特征**: 承诺还款次数、承诺兑现率、沟通配合度、态度变化趋势

**注意事项**>
> - 意愿和能力要分开评估
> - 有意愿无能力的客户可协商分期
> - 无意愿的客户需升级催收方式

#### 4. 还款能力评估模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 客户还款能力评估模型 |
| **模型类型** | 回归/评分 |
| **业务目标** | 评估客户实际还款能力 |

**样本选取**

- **样本**: 逾期客户

**Y标签定义**

- **Y**: 客户实际可还款金额/比例

**模型开发**

- **特征**: 收入变化、资产状况、负债变化、可变现资产

**注意事项**>
> - 能力评估需结合收入和负债
> - 可协商分期方案

### 1.2 催收策略模型

#### 5. 催收方式最优匹配模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 催收方式智能匹配模型 |
| **模型类型** | 推荐算法 |
| **业务目标** | 为每个案件匹配最优催收方式 |

**样本选取**

- **样本**: 历史催收记录

**Y标签定义**

- **Y**: 各催收方式的有效率

**模型开发**

- **催收方式库**: 电话、短信、上门、律师函、诉讼等
- **算法**: Thompson Sampling / UCB
- **匹配特征**: 客户特征、逾期特征、历史响应特征

**注意事项**>
> - 不同客户适合不同催收方式
> - 年轻客户可侧重短信、微信
> - 外地客户电话为主

#### 6. 催收时机优化模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 催收时机优化模型 |
| **模型类型** | 时序优化 |
| **业务目标** | 确定最佳催收时间节点 |

**样本选取**

- **样本**: 历史催收记录

**Y标签定义**

- **Y**: 不同时间点催收的响应率

**模型开发**

- **特征**: 客户活跃时间分布、工作日/节假日、时段效果分析

**注意事项**>
> - 周一至周五上午10-12点、下午2-5点效果较好
> - 避免在客户可能忙碌的时间段联系

#### 7. 催收频率优化模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 催收频率优化模型 |
| **模型类型** | 强化学习 |
| **业务目标** | 确定最优催收频率 |

**样本选取**

- **样本**: 不同催收频率下的催收效果

**Y标签定义**

- **Y**: 催收成本与回收率的平衡

**模型开发**

- **目标**: 在有限资源下最大化回收率

**注意事项**>
> - 频率太高可能导致客户反感
> - 频率太低可能错过最佳时机
> - 建议M1每天1次，M2每天2次，M3持续跟进

#### 8. 催收优先级排序模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 催收案件优先级排序模型 |
| **模型类型** | 排序模型 |
| **业务目标** | 按回收价值排序催收案件优先级 |

**样本选取**

- **样本**: 待催收案件

**Y标签定义**

- **Y**: 案件回收价值 = 预计回收金额 × 回收概率 - 催收成本

**模型开发**

- **算法**: Learning to Rank
- **应用**: 催收资源优先分配

**注意事项**>
> - 高价值案件优先催收
> - 避免在低价值案件上浪费资源

### 1.3 特殊催收模型

#### 9. 协商还款方案模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 协商还款方案推荐模型 |
| **模型类型** | 优化模型 |
| **业务目标** | 为困难客户制定个性化协商方案 |

**样本选取**

- **样本**: 历史协商还款案例

**Y标签定义**

- **Y**: 协商方案的实际履约率

**模型开发**

- **方案要素**: 减免金额、分期期数、首付比例、宽限期
- **算法**: 线性规划 + 规则引擎
- **约束条件**: 公司最小回收比例、客户承受能力

**注意事项**>
> - 协商还款是双赢方案
> - 需评估客户真实还款能力
> - 建议减免幅度不超过本金的20%
> - 需签订书面协议

#### 10. 逃逸风险预警模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 客户逃逸风险预警模型 |
| **模型类型** | 二分类 |
| **业务目标** | 识别可能逃逸的客户 |

**样本选取**

- **逃逸定义**: 失去联系超过30天或资产异常转移

**Y标签定义**

- **Y=1**: 客户出现逃逸行为
- **Y=0**: 客户保持联系

**模型开发**

- **特征**:
  - 失联特征：联系不上次数增加、地址变更未告知
  - 资产特征：资产异常转移、账户异常变动
  - 行为特征：突然结清小额欠款、异常大额消费

**注意事项**>
> - 逃逸客户追偿困难
> - 建议逃逸前预警，提前采取保全措施
> - 失联超过15天建议立案诉讼

## 二、诉讼模型（4个）

### 2.1 诉讼决策模型

#### 11. 诉讼必要性评估模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 诉讼必要性评估模型 |
| **模型类型** | 二分类 |
| **业务目标** | 判断案件是否需要进入诉讼程序 |

**样本选取**

- **样本**: 历史诉讼案件

**Y标签定义**

- **Y=1**: 诉讼是收回欠款的必要手段
- **Y=0**: 其他催收方式更有效

**模型开发**

- **特征**: 欠款金额、逾期时长、客户资产状况、诉讼成本、胜诉概率

**注意事项**>
> - 诉讼成本高，需权衡收益
> - 建议欠款金额>5000元再考虑诉讼
> - 需评估客户可执行财产

| 项目 | 内容 |
|------|------|
| **模型名称** | 诉讼收益评估模型 |
| **模型类型** | 回归 |
| **业务目标** | 评估诉讼的预期收益 |

**样本选取**

- **样本**: 历史诉讼结果

**Y标签定义**

- **Y**: 诉讼实际回收金额

**模型开发**

- **特征**: 诉讼成本、律师费、执行难度、客户可执行财产

#### 14. 执行效果预测模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 案件执行效果预测模型 |
| **模型类型** | 回归 |
| **业务目标** | 预测判决后的执行效果 |

**样本选取**

- **样本**: 历史已执行案件

**Y标签定义**

- **Y**: 执行回收率

**模型开发**

**注意事项**>

> - 建议诉讼前保全财产

## 催收策略矩阵参考

| 逾期天数 | 风险等级 | 推荐催收方式 | 催收频次 | 备注 |
|----------|----------|--------------|----------|------|
| M1 (1-30天) | 低 | 短信提醒 → 电话 | 1次/天 | 侧重提醒 |
| M2 (31-60天) | 中 | 电话密集催收 | 2-3次/天 | 施加压力 |
| M3 (61-90天) | 高 | 电话 + 上门 | 3次/以上 | 严重警告 |
| M4+ (90天+) | 极高 | 律师函/诉讼 | 持续跟进 | 法律手段 |

> **文档说明**
> - 贷后模型共14个：催收模型10个 + 诉讼模型4个
> - 贷后模型核心目标是最大化回收率的同时控制催收成本
> - **P0优先级模型建议优先开发**
> - 诉讼决策需综合考虑收益、成本、时间精力
