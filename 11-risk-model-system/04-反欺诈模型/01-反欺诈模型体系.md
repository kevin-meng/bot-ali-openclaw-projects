# 反欺诈风控模型体系

## 模型优先级说明

| 优先级 | 评分 | 说明 |
|--------|------|------|
| **P0** | 9-10分 | 核心防线，必须优先开发 |
| **P1** | 7-8分 | 重要风控，显著提升风控效果 |
| **P2** | 5-6分 | 优化补充，提升风控精细度 |
| **P3** | 3-4分 | 锦上添花，后续迭代 |

---

## 一、交易欺诈模型（6个）

### 1.1 交易监控模型

#### 1. 交易异常检测模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 实时交易异常检测模型 |
| **模型类型** | 异常检测/二分类 |
| **业务目标** | 实时检测异常交易行为 |

**样本选取**

- **样本范围**: 历史交易数据
- **样本量**: 不少于100万条交易记录
- **正负样本比例**: 1:100 ~ 1:1000
- **时间窗口**: 实时流式处理

**Y标签定义**

- **Y=1**: 交易被确认为欺诈
- **Y=0**: 正常交易

**模型开发**

- **特征维度**:
  - 交易特征：金额、频次、时间、地点、商户类型
  - 账户特征：历史交易均值、波动性、活跃时间
  - 设备特征：设备指纹、IP地址、地理位置
  - 行为特征：输入速度、页面停留时间、操作轨迹
- **算法**: Isolation Forest + XGBoost + 规则引擎
- **延迟要求**: <100ms
- **召回率要求**: ≥0.80
- **误报率目标**: <5%

**注意事项**:
> - 欺诈损失是纯损失，无法通过定价覆盖
> - 必须保证召回率，漏掉一个欺诈可能损失数万
> - 误报率需控制在5%以下，否则影响客户体验
> - 建议实时风控，延迟<100ms

#### 2. 大额交易预警模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 大额交易风险评估模型 |
| **模型类型** | 二分类 |
| **业务目标** | 评估大额交易的风险程度 |

**样本选取**

- **样本定义**: 单笔交易金额 > 客户历史平均交易金额的5倍

**Y标签定义**

- **Y=1**: 大额交易后出现逾期或欺诈
- **Y=0**: 大额交易正常

**模型开发**

- **特征**: 大额金额占收入比、交易后账户余额变化、大额交易频次

**注意事项**:
> - 维信金科额度较小，大额交易需重点关注
> - 建议单笔超过2万元触发人工确认

#### 3. 交易地点异常模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 交易地点异常识别模型 |
| **模型类型** | 异常检测 |
| **业务目标** | 识别非常规地点的交易 |

**样本选取**

- **样本**: 历史交易地点数据

**Y标签定义**

- **Y=1**: 地点异常（与常驻地差异过大）
- **Y=0**: 正常地点

**模型开发**

- **特征**: 常住地址、历史交易地点、当前交易地点、IP定位、设备定位

**注意事项**:
> - 短时间内跨城市交易是风险信号
> - 建议结合IP和设备定位综合判断

### 1.2 交易模式识别

#### 4. 洗钱交易识别模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 可疑洗钱交易识别模型 |
| **模型类型** | 异常检测/规则 |
| **业务目标** | 识别涉嫌洗钱的交易模式 |

**样本选取**

- **监管要求**: 符合反洗钱规则的可疑交易
- **样本量**: 不少于1000例可疑案例

**Y标签定义**

- **Y=1**: 确认涉嫌洗钱
- **Y=0**: 正常交易

**模型开发**

- **洗钱特征**:
  - 资金快进快出
  - 分散转入集中转出
  - 夜间频繁交易
  - 与高风险地区交易
  - 交易金额接近监管阈值
- **算法**: 规则引擎 + 机器学习
- **上报标准**: 符合监管要求的可疑交易

**注意事项**:
> - 反洗钱是监管合规要求
> - 需符合监管上报标准
> - 建议可疑交易自动上报

#### 5. 套现交易识别模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 信用卡套现识别模型 |
| **模型类型** | 二分类 |
| **业务目标** | 识别涉嫌信用卡套现的交易 |

**样本选取**

- **样本**: 贷记卡交易数据

**Y标签定义**

- **Y=1**: 确认套现行为
- **Y=0**: 正常消费

**模型开发**

- **套现特征**:
  - 整数金额交易频繁
  - 交易时间集中在特定时段
  - 商户类别异常（低费率商户大额交易）
  - 交易金额与商户类型不匹配
  - 还款后立即大额刷出

**注意事项**:
> - 套现资金去向不明，风险较高
> - 建议对套现嫌疑客户降低额度

#### 6. 虚假交易识别模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 虚假交易识别模型 |
| **模型类型** | 二分类 |
| **业务目标** | 识别虚假交易行为 |

**样本选取**

- **样本**: 交易数据 + 商户数据

**Y标签定义**

- **Y=1**: 确认为虚假交易
- **Y=0**: 真实交易

**模型开发**

- **特征**:
  - 商户交易量异常
  - 退货/退款率异常高
  - 交易时间分布异常
  - 关联账户交易

## 二、身份欺诈模型（5个）

### 2.1 身份验证模型

#### 7. 身份信息真实性验证模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 身份信息真实性验证模型 |
| **模型类型** | 二分类/匹配 |
| **业务目标** | 验证客户身份信息的真实性 |

**样本选取**

- **数据源**: 身份证信息、公安部数据、运营商数据

**Y标签定义**

- **Y=1**: 身份信息不真实（冒用、伪造）
- **Y=0**: 身份信息真实

**模型开发**

- **验证维度**:
  - 身份证号码格式校验
  - 姓名与身份证匹配
  - 身份证照片与本人比对（人脸识别）
  - 证件有效期校验
  - 身份证挂失/黑名单校验
- **算法**: 规则引擎 + OCR + 人脸识别

**注意事项**:
> - 身份验证是第一道防线
> - 建议活体检测+人脸比对双重验证
> - 身份证黑名单需实时更新

#### 8. 生物特征识别模型 [P0-9分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 生物特征身份认证模型 |
| **模型类型** | 深度学习 |
| **业务目标** | 通过生物特征确认身份 |

**样本选取**

- **数据源**: 人脸数据、指纹数据、声纹数据

**Y标签定义**

- **Y=1**: 生物特征匹配失败
- **Y=0**: 生物特征匹配成功

**模型开发**

- **特征**:
  - 人脸识别：3D活体检测、比对得分
  - 指纹识别：指纹匹配度
  - 声纹识别：声纹比对得分
- **算法**: CNN + FaceNet

**注意事项**:
> - 3D活体检测防止照片、视频攻击
> - 建议与身份验证结合使用

### 2.2 欺诈行为识别

#### 9. 团伙欺诈识别模型 [P0-9分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 团伙欺诈检测模型 |
| **模型类型** | 图计算/异常检测 |
| **业务目标** | 识别有组织的欺诈团伙 |

**样本选取**

- **方法**: 无监督聚类 + 有监督验证

**Y标签定义**

- **Y=1**: 属于欺诈团伙
- **Y=0**: 正常客户

**模型开发**

- **构建关联图**:
  - 共同设备
  - 共同IP地址
  - 共同收货地址
  - 共同联系人
  - 同一时间申请
- **算法**: 图数据库 + Louvain社区发现 + Graph Neural Network
- **特征**:
  - 社区规模
  - 社区聚集度
  - 社区内逾期率
  - 信息传递路径

**注意事项**:
> - 团伙欺诈损失大，一个团伙可能骗几十万
> - 建议定期更新团伙特征库
> - 团伙成员需全部拦截

#### 10. 伪冒申请识别模型 [P0-9分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 伪冒申请检测模型 |
| **模型类型** | 二分类 |
| **业务目标** | 检测伪冒他人身份的申请 |

**样本选取**

- **样本**: 历史申请记录 + 事后确认的伪冒案例

**Y标签定义**

- **Y=1**: 确认为伪冒申请
- **Y=0**: 正常申请

**模型开发**

- **伪冒特征**:
  - 身份信息与历史不符
  - 设备指纹变化
  - 绑卡信息异常
  - 申请行为异常（填写时长、流程跳过）
  - 活体检测失败
  - 证件照片与公安照片差异大

**注意事项**:
> - 伪冒申请发现后需报警
> - 建议与公安数据实时比对

#### 11. 欺诈画像模型 [P1-7分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 欺诈客户画像模型 |
| **模型类型** | 画像/标签 |
| **业务目标** | 构建欺诈客户特征画像 |

**样本选取**

- **样本**: 所有确认的欺诈案例

**Y标签定义**

- **标签**: 欺诈类型、欺诈程度、欺诈手法

**模型开发**

- **画像维度**:
  - 人口统计特征：年龄、性别、地域分布
  - 行为特征：申请时间、设备偏好、操作习惯
  - 设备特征：设备类型、模拟器检测、IP分布
  - 关联特征：联系人网络、商户网络
  - 时间特征：欺诈高发时段、季节性
- **应用**: 规则优化、特征补充、策略调整

**注意事项**:
> - 欺诈手法不断进化，需定期更新画像
> - 建议每月分析最新欺诈案例

## 反欺诈策略层级

| 层级 | 防线 | 策略/模型 | 处理方式 |
|------|------|-----------|----------|
| 第一层 | 预防 | 身份验证、生物识别、设备指纹 | 拦截伪造身份 |
| 第二层 | 监控 | 交易监控、异常检测、规则引擎 | 实时拦截风险交易 |
| 第三层 | 识别 | 团伙识别、伪冒识别、欺诈画像 | 发现已渗透的欺诈 |
| 第四层 | 响应 | 冻结账户、报警、诉讼 | 事后处置和追偿 |

## 关键指标监控

| 指标 | 定义 | 预警阈值 |
|------|------|----------|
| 欺诈率 | 欺诈金额/总放款额 | >0.5% |
| 欺诈拦截率 | 被拦截欺诈/全部欺诈 | <85% |
| 误报率 | 正常被拦截/全部拦截 | >10% |
| 冒名顶替率 | 冒名成功/全部申请 | >0.1% |
| 团伙识别覆盖率 | 团伙被识别/全部团伙 | >80% |
