## 一、交易欺诈模型（6个）

| 模型名称 | 功能 | Y标签 | 应用场景 |

### 1.2 核心交易欺诈模型

#### 1.2.1 交易欺诈评分模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 实时交易欺诈评分模型                           │
│  模型用途: 评估每笔交易是否为欺诈                          │
│  Y标签定义:                                              │
│    Y=1: 确认为欺诈交易（通过调查/投诉确认）              │
│    Y=0: 正常交易                                        │
│  样本选取:                                               │
│    - 观察期: 交易发生时刻                                │
│    - 表现期: 交易后7天内确认                            │
│    - 样本量: 正样本≥5000, 负样本≥50000                  │
└─────────────────────────────────────────────────────────┘
```

**实时特征维度:**

| 类别 | 特征数 | 示例 | 时效要求 |
|------|--------|------|----------|
| 交易特征 | 20 | 金额、时间、频率、商家 | 实时 |
| 账户特征 | 15 | 登录设备、IP、位置 | 实时 |
| 历史行为 | 25 | 历史交易模式、习惯 | T+1 |
| 关系网络 | 20 | 关联账户、设备 | T+1 |
| 外部情报 | 10 | 欺诈黑名单、风险IP | 实时 |

```
┌─────────────────────────────────────────────────────────┐
```

**异常检测维度:**

| 异常类型 | 检测指标 | 阈值 |
|----------|----------|------|
| 金额异常 | Z-Score > 3 | 3σ |
| 频率异常 | 突增200% | 阈值 |
| 时间异常 | 非常用时段 | 偏离度 |
| 商户异常 | 新商户/高风险商户 | 名单 |
| 设备异常 | 新设备/模拟器 | 识别 |
| IP异常 | 代理/VPN/数据中心 | 识别 |

#### 1.2.3 套现检测模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 信用卡套现检测模型                             │
│  模型用途: 识别利用信用卡分期/额度进行套现的行为           │
│  Y标签定义:                                              │
│    Y=1: 确认套现（资金流向异常+调查确认）                │
│    Y=0: 正常消费                                        │
│  样本选取:                                               │
│    - 商户交易数据 + 资金流向                             │
│    - 正样本≥2000, 负样本≥20000                          │
└─────────────────────────────────────────────────────────┘
```

**套现特征:**

| 类别 | 特征 | 说明 |
|------|------|------|
| 商户特征 | 套现商户交易占比 | 高风险商户 |
| 交易特征 | 大额整数交易 | 如9999、10000 |
| 交易特征 | 交易时间集中 | 短时间内多笔 |
| 交易特征 | 交易间隔规律 | 固定间隔 |
| 资金特征 | 资金到账即转 | T+0转出 |
| 资金特征 | 转出账户敏感 | 借记卡/理财 |

**套现规则示例:**

```python
# 规则1: 高风险商户 + 大额整数
if merchant.risk_level == "HIGH" and transaction.amount in [5000, 9999, 10000]:
    flag = "SUSPICIOUS"

# 规则2: 资金快进快出
if time_to_transfer < 60:  # 60分钟内转出
    flag = "SUSPICIOUS"

# 规则3: 整数金额 + 短间隔
if is_integer_amount and time_interval < 300:  # 5分钟内
    flag = "SUSPICIOUS"
```

### 2.2 核心身份欺诈模型

#### 2.2.1 身份核验模型

```
┌─────────────────────────────────────────────────────────┐
│  模型名称: 身份信息核验模型                               │
```

**核验维度:**

| 核验项目 | 数据源 | 一致性标准 |
|----------|--------|------------|

| 姓名 | 公安数据库 | 完全匹配 |
| 照片 | 公安数据库 | 相似度≥80% |
| 手机号 | 运营商 | 匹配 |
| 银行卡 | 银行验证 | 匹配 |
| 学历 | 学信网 | 匹配 |
| 社保 | 社保局 | 匹配 |
