## 📊 模型体系架构

本体系涵盖 **100个核心风控模型**，分为5大阶段：

| 阶段 | 模型数量 | 核心功能 |
|------|----------|----------|
| 贷前 | 40个 | 准入筛选、风险定价、额度授信 |
| 贷中 | 20个 | 额度管理、风险预警、客户价值提升 |
| 贷后 | 14个 | 催收策略、诉讼决策、资产回收 |
| 反欺诈 | 11个 | 交易监控、身份验证、团伙识别 |
| 组合管理 | 15个 | 风险计量、资产定价、收益优化 |

## 📋 模型开发标准化框架

### 1. 样本选取标准

| 维度 | 规范 |
|------|------|
| **时间窗口** | 观察期≥12个月，表现期≥6个月 |
| **样本量** | 正负样本比例不低于1:3 |
| **样本划分** | 训练集70%、验证集15%、测试集15% |
| **偏移处理** | 采用时间序列分层抽样 |

### 2. Y标签定义

| 模型类型 | Y标签 | 定义规则 |
|----------|-------|----------|
| 违约模型 | bad | 逾期≥90天 (M3+) |
| 欺诈模型 | fraud | 确认欺诈事件 |
| 流失模型 | churn | 90天无交易且无还款 |
| 催收模型 | recover | 催收后还款 |

### 3. 模型开发流程

```
需求分析 → 特征工程 → 模型训练 → 验证调优 → 部署上线 → 监控迭代
```
