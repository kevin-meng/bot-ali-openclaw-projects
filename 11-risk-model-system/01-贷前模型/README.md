## 一、准入模型（10个）

### 1.1 基础准入评分卡

| 模型名称 | 模型用途 | Y标签定义 | 样本选取 |
|----------|----------|------------|----------|
| 基础准入分 | 客户初筛 | 逾期≥90天=1，否则=0 | 近24个月申请客户 |
| 年龄准入模型 | 年龄段风险评估 | 同上 | 同上 |
| 地域准入模型 | 地区风险分层 | 同上 | 同上 |
| 职业准入模型 | 职业风险评估 | 同上 | 同上 |
| 收入准入模型 | 还款能力评估 | 同上 | 同上 |
| 负债准入模型 | 负债水平评估 | 同上 | 同上 |
| 信用历史准入模型 | 信用时长评估 | 同上 | 同上 |
| 贷款目的准入模型 | 用途风险评估 | 同上 | 同上 |
| 设备准入模型 | 设备风险识别 | 同上 | 同上 |
| 多头借贷准入模型 | 共债风险评估 | 同上 | 同上 |

### 1.2 Y标签定义详解

```
Y = 1 (Bad): 贷款发放后90天内出现M3+逾期
Y = 0 (Good): 贷款发放后正常还款≥12个月
```

**样本选取规则：**
- 观察期：T-24至T-12个月
- 表现期：T-12至T个月
- 样本量要求：正样本≥2000，负样本≥6000
- 排除变量：神秘客户、测试客户、内部员工

### 1.3 特征维度

| 特征类别 | 特征数量 | 示例 |
|----------|----------|------|
| 人口属性 | 8 | 年龄、性别、学历、婚姻状态 |
| 职业信息 | 6 | 职业类型、工作年限、收入来源 |
| 财务状况 | 10 | 收入、负债、资产、支出 |
| 信用历史 | 8 | 信用时长、历史逾期次数 |
| 行为特征 | 12 | 申请渠道、时间偏好、设备信息 |

### 1.4 模型开发规范

```python
# 样本选取SQL示例
SELECT *
FROM loan_application
WHERE apply_date BETWEEN '2024-01-01' AND '2024-12-31'
  AND product_type IN ('personal_loan', 'credit_card')
  AND exclude_flag = 0
```

| 收入负债匹配模型 | M3+逾期 | 3个月 | 9个月 |
| 还款历史模型 | M3+逾期 | 12个月 | 12个月 |
| 征信综合风险模型 | M3+逾期 | 6个月 | 12个月 |

### 2.2 Y标签定义

```
标准定义:
- Bad: 任何贷款/信用卡账户在表现期内出现M3+逾期
- Good: 所有账户在表现期内无M3+逾期

特殊处理:
- 表现期内新开户账户不参与Y标签计算
- 冻结、止付等非逾期状态作为中立样本
```

### 2.3 样本选取规范

| 维度 | 要求 |
|------|------|
| 信用报告完整性 | 必须包含完整征信报告 |
| 账户数量 | ≥1个活跃账户 |
| 查询间隔 | 申请前30天内有征信查询 |
| 样本分层 | 按地区、年龄段、收入分层抽样 |

## 三、替代数据模型（10个）

### 3.1 替代数据评分系列

| 模型名称 | 数据源 | Y标签 | 应用场景 |
|----------|--------|-------|----------|
| 移动运营商模型 | 通话、流量、账单 | M3+逾期 | 补充征信 |
| 电商消费模型 | 淘宝、京东消费记录 | M3+逾期 | 收入验证 |
| 社保公积金模型 | 社保缴纳、公积金 | M3+逾期 | 职业验证 |
| 税务模型 | 个税申报、缴纳 | M3+逾期 | 收入验证 |
| 物流地址模型 | 收货地址稳定性 | M3+逾期 | 稳定性评估 |
| 航旅模型 | 航班出行记录 | M3+逾期 | 消费能力 |
| 保险模型 | 商业保险投保 | M3+逾期 | 资产验证 |
| 教育模型 | 学历、培训记录 | M3+逾期 | 职业评估 |
| 社交模型 | 社交网络特征 | M3+逾期 | 欺诈识别 |
| 设备行为模型 | App使用行为 | M3+逾期 | 风险识别 |

### 3.2 Y标签定义与样本选取

```
Y标签定义:
- 与征信模型一致，M3+逾期=1，正常=0

样本选取特殊规则:
- 必须获得用户授权
- 数据质量：完整度≥80%
- 时间对齐：替代数据与申请时间差≤7天
```

### 3.3 特征构建规范

| 数据类型 | 核心特征 | 处理方式 |
|----------|----------|----------|
| 通话记录 | 通话频率、联系人数量、夜间通话比例 | 脱敏后统计 |
| 账单数据 | 月均消费、欠费次数、充值频率 | 聚合统计 |
| 电商数据 | 品类分布、价格区间、退货率 | 类别编码 |
| 社保数据 | 缴纳时长、基数、连续性 | 缺失值填充 |
| 位置数据 | 地址变更频率、常驻城市 | 哈希脱敏 |

### 3.4 隐私合规要求

```
数据使用原则:
1. 必须获得用户明确授权
2. 数据仅用于信贷风控目的
3. 存储需加密，保留期限≤授信后24个月
4. 禁止数据共享给第三方
5. 定期进行数据安全审计
```

## 四、产品特定模型（8个）

### 4.1 产品分类与模型配置

| 产品类型 | 模型数量 | 核心模型 |
|----------|----------|----------|
| 现金贷 | 3 | 额度模型、期限模型、风险定价模型 |
| 消费贷 | 3 | 场景准入模型、分期偏好模型、费用敏感度模型 |
| 信用卡 | 2 | 额度授信模型、卡片等级模型 |
| 经营贷 | 3 | 经营状况模型、现金流模型、行业风险模型 |

### 4.2 现金贷模型

#### 模型：额度模型
```
Y标签: 逾期≥30天=1，否则=0
样本: 近18个月现金贷客户
特征: 收入、负债、历史贷款表现、活跃度
```

#### 模型：期限模型
```
Y标签: 提前还款=0，正常还款/逾期=1
样本: 有不同期限选择的客户
特征: 收入波动、现金流特征、利率敏感度
```

#### 模型：风险定价模型
```
Y标签: M3+逾期=1，正常=0
样本: 不同定价策略下的客户
特征: 风险等级、市场利率、竞品定价
```

### 4.3 消费贷模型

#### 模型：场景准入模型
```
Y标签: M3+逾期=1，正常=0
样本: 不同消费场景的客户
特征: 场景类型、商户风险、消费品类
```

#### 模型：分期偏好模型
```
Y标签: 选择分期=1，提前还款=0
样本: 有分期选择机会的客户
特征: 消费金额、收入水平、历史分期行为
```

#### 模型：费用敏感度模型
```
Y标签: 对费用敏感（取消申请）=1，继续=0
样本: 展示费用信息后离开的客户
特征: 费用透明度感知、比较行为、决策时间
```

### 4.4 信用卡模型

#### 模型：额度授信模型
```
Y标签: 额度过低导致流失=1，正常使用=0
样本: 额度调整后的客户
特征: 消费能力、收入变化、竞争授信
```

#### 模型：卡片等级模型
```
Y标签: 高等级卡逾期=1，正常=0
样本: 不同等级卡片客户
特征: 资产水平、消费能力、历史信用
```

### 4.5 经营贷模型

#### 模型：经营状况模型
```
Y标签: M3+逾期=1，正常=0
样本: 小微企业主
特征: 流水稳定性、开票金额、纳税记录
```

#### 模型：现金流模型
```
Y标签: 现金流断裂导致逾期=1，正常=0
样本: 经营贷逾期客户
特征: 经营现金流、应收账款、账期结构
```

#### 模型：行业风险模型
```
Y标签: 行业整体违约率
样本: 按行业分组的客户群
特征: 行业周期、政策影响、竞争格局
```
