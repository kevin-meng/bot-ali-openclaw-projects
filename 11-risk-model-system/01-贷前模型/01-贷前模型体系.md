# 贷前风控模型体系

## 一、准入模型（15个）- 优先级排序

### 优先级说明

| 优先级 | 评分 | 说明 |
|--------|------|------|
| **P0** | 9-10分 | 核心防线，必须优先开发，直接影响坏账率 |
| **P1** | 7-8分 | 重要风控，显著提升风控效果 |
| **P2** | 5-6分 | 优化补充，提升风控精细度 |
| **P3** | 3-4分 | 锦上添花，后续迭代 |

### 1.1 基础准入评分卡

#### 1. 基本信息准入模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 基础准入评分卡 |
| **模型类型** | 二分类 |
| **业务目标** | 判断客户是否满足基本准入条件 |

**样本选取**

- **样本范围**: 近24个月内有完整申请记录的客户
- **样本量**: 正负样本比例控制在1:3至1:5
- **时间窗口**: 观察期12个月，表现期12个月
- **抽样方法**: 分层抽样，确保各产品类型、各渠道样本比例均衡

**Y标签定义**

- **正样本(Y=1)**: 观察期内发生90天以上逾期的客户
- **负样本(Y=0)**: 观察期内正常还款或30天以内短期逾期且已还清的客户
- **排除样本**: 欺诈样本、灰色名单客户、测试样本

**模型开发**

- **特征维度**: 基本信息(年龄、学历、婚姻、居住状况)、职业信息(公司规模、职位、年限)、收入负债比
- **算法**: Logistic Regression + XGBoost Ensemble
- **验证方式**: 5折交叉验证 + 时间外样本验证
- **KS值**: ≥0.35
- **AUC**: ≥0.75
- **PSI**: ≤0.1

**注意事项**:
> - 这是风控第一道防线，必须保证稳定性
> - 建议用逻辑回归作为主模型，可解释性强
> - 需配置硬规则拦截（如年龄<22岁、负债率>70%等）
> - 需与反欺诈名单联动

#### 2. 年龄段准入模型 [P2-5分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 年龄段准入评分卡 |
| **模型类型** | 二分类 |
| **业务目标** | 针对不同年龄段客户差异化管理 |

**样本选取**

- **样本范围**: 按年龄段分层后的申请客户
- **年龄段划分**: 22-25岁、26-30岁、31-35岁、36-40岁、41-50岁、50岁以上
- **各年龄段样本量**: 不少于5000条

**Y标签定义**

- **正样本**: 90天+逾期
- **负样本**: 正常结清
- **标签生成时间**: 授信后12个月

**模型开发**

- **特征**: 年龄、年龄段对应的风险特征包、该年龄段历史表现
- **算法**: 分年龄段训练的独立模型
- **KS要求**: 各年龄段 ≥0.30

**注意事项**:
> - 依赖基础准入模型的分数作为输入
> - 22-25岁年轻客群逾期率较高，需重点关注
> - 可用于差异化定价和额度

### 1.2 征信准入模型

#### 3. 征信报告准入模型 [P0-10分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 央行征信准入评分卡 |
| **模型类型** | 二分类 |
| **业务目标** | 基于央行征信报告数据判断准入资格 |

**样本选取**

- **样本范围**: 有完整央行征信报告的申请客户
- **样本要求**: 征信息信数据完整度≥90%
- **时间窗口**: 观察期6个月，表现期12个月

**Y标签定义**

- **Y=1**: 出现90天+逾期或出现2次以上60天+逾期
- **Y=0**: 无严重逾期记录

**模型开发**

- **特征维度**:
  - 信贷账户数、贷记卡账户数
  - 逾期次数、逾期金额、逾期最长月数
  - 查询次数、查询机构数
  - 负债率、新增负债率
  - 贷款类型分布、还款记录详情
- **算法**: LightGBM
- **IV值筛选**: 特征IV>0.02

**注意事项**:
> - 维信金科主要依赖征信数据，这是核心模型
> - 需关注征信的查询次数（硬查询过多是风险信号）
> - 负债率是核心指标，建议设置硬规则：负债率>75%直接拒绝
> - 需定期校准PD，确保与实际逾期率匹配

| 项目 | 内容 |
|------|------|
| **模型名称** | 网贷征信准入评分 |
| **模型类型** | 二分类 |
| **业务目标** | 评估客户在互联网信贷平台的行为表现 |

**样本选取**

- **数据源**: 百行征信、芝麻信用、腾讯征信等
- **样本量**: 正样本不少于2000例

**Y标签定义**

- **Y=1**: 网贷平台90天+逾期
- **Y=0**: 无严重逾期或无网贷记录

**模型开发**

**注意事项**:
> - 维信金科客户多为"征信白户"，网贷数据是重要补充
> - 多头借贷是核心风险信号，建议硬规则：网贷平台≥5个且未结清直接拒绝
> - 需关注频繁申请行为（短期内多次申请）

### 1.3 替代数据准入模型

#### 6. 运营商数据准入模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 运营商数据风险评分 |
| **模型类型** | 二分类 |
| **业务目标** | 利用运营商数据补充传统征信空白 |

**样本选取**

- **数据源**: 运营商账单、通话记录、流量使用等
- **样本要求**: 有效通话记录≥6个月

**Y标签定义**

- **Y=1**: 客户在业务平台90天+逾期
- **Y=0**: 正常还款客户

**模型开发**

- **特征维度**:
  - 通话频次、通话时长、联系人数量
  - 夜间通话比例、工作时间通话比例
  - 欠费次数、停机次数
  - 号码在网时长、月均消费金额
  - 漫游次数、亲情号码联系频率
- **算法**: XGBoost
- **缺失处理**: 缺失率>30%的特征单独建模或用填充值

**注意事项**:
> - 运营商数据是"征信白户"的重要补充
> - 在网时长<6个月需重点关注（稳定性不足）
> - 欠费次数>3次是风险信号
> - 注意合规：需客户授权

## 二、贷前风险定价模型（10个）

### 16. 风险定价基础模型 [P1-8分]

| 项目 | 内容 |
|------|------|
| **模型名称** | 风险定价系数模型 |
| **模型类型** | 回归模型 |
| **业务目标** | 确定不同风险等级客户的差异化定价系数 |

**样本选取**

- **样本范围**: 已有完整还款记录的客户
- **样本量**: 不少于50000条

**Y标签定义**

- **Y**: 客户实际风险损失率 = 逾期金额 / 授信金额

**模型开发**

- **算法**: GLM (Gamma Regression)
- **定价公式**: 利率 = 基础利率 + 风险定价系数 × 风险调整因子
- **目标**: 使预期收益覆盖预期损失

**注意事项**:
> - 定价直接影响利润，需平衡收益与风险
> - 需符合监管利率上限要求
> - 建议分层：优质客户利率下限，敏感客户利率上限
