# 驾校备考App

## 项目概述

### 背景（公司战略层面）
（同08职业考试备考平台的背景）

公司在探索职业培训场景的战略布局，本项目是第二个具体方向。

### 背景（业务逻辑）
- 目前同行业内很多的金融机构转型去做了车抵贷
- 如果想要做车抵贷，是要找到有车的用户
- 这是一个漏斗：
  - 海量用户 → 有驾照的客户 → 有车的客户 → 愿意贷款的客户
- 关键是要找到有驾照的客户

### 目标
- 开发一个针对家校教育类的App
- 主要是针对驾校备考的
- 提供考试的题库信息
- 解决用户痛点：备考人群（底层没受过什么文化教育）背题痛苦
- 游戏化方式：交互式画面
- 配以语音解释：告诉他们为什么会这样做
- 目的是：帮助用户通过考试，同时收集积累海量用户

### 漏斗逻辑
1. 海量用户：需要考驾照/准备考驾照的人
2. 有驾照的客户：通过App备考并获取驾照
3. 有车的客户：逐步引导
4. 贷款客户：最终导流到车抵贷业务

### 核心功能
1. **题库系统**：海量驾考试题
2. **AI解析**：语音+文字解释题目
3. **游戏化学习**：
   - 交互式画面
   - 进度奖励
   - 错题复习
   - 模拟考试
4. **语音辅助**：告诉用户为什么选这个答案
5. **用户数据**：沉淀学习行为数据

### 目标用户
- 准备考驾照的人群
- 科目一、科目四考生为主
- 文化程度不高的用户（需要更易理解的学习方式）

### 变现/导流
1. **用户积累**：快速获取海量用户
2. **数据沉淀**：学习行为数据
3. **金融导流**：最终导流到车抵贷业务

### 技术方案
- 前端：React Native / Flutter（跨平台）
- 后端：Python FastAPI
- AI：语音合成、题目解析
- 题库：各地区驾考试题
